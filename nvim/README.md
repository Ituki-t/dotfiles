# nvim-config

My personal Neovim configuration.

Originally based on kickstart.nvim.

## Features

- Alpha Dashboard
- Bufferline
- Neo-tree
- Telescope
- Lualine
- Noice
- ToggleTerm
- Copilot
- Indent Blankline (ibl)

## Requirements

- Neovim (latest stable)
- Git
- Nerd Font
- ripgrep
- fd
- Node.js
